# НВО и ДЗИ — графично сравнение на училищата

Сайт за визуално сравнение на училищата в България по резултати от Национално външно оценяване (НВО) и Държавни зрелостни изпити (ДЗИ).

**https://ivandavidov.github.io/nvo**

## Какво предлага сайтът

- **Начална страница** — търсене и карти за четирите изпита с последните резултати и тенденция
- **Графики за сравнение** — интерактивни диаграми по БЕЛ и МАТ (или втора матура) за избрани училища, с броя явили се ученици
- **Класации** — подреждане на училищата по среден успех за последните 3 години, с информация за брой явили се ученици
- **Класации по градове и години** — отделни страници за [всеки град](https://ivandavidov.github.io/nvo/7/sofia/) и [всяка година](https://ivandavidov.github.io/nvo/7/2025/)
- **Балове по паралелки след 7 клас** — минимален и максимален бал по паралелки и класирания за [~130 града](https://ivandavidov.github.io/nvo/7/balove/)
- **Топ училища** — бързо добавяне на топ 3, 5 или 10 държавни/частни училища от всеки град в графиката
- **Страница за всяко училище** — [профил по код](https://ivandavidov.github.io/nvo/school/2216306/) с резултати по всички класове, рангове (национален, в града, медиана) и графики
- **Търсене навсякъде** — училища, градове и страници от всяка страница (клавиш `/` или Ctrl/⌘K)
- **CSV експорт** — изтегляне на данните за отделен град или за всички градове
- **PDF отчети** — генериране на PDF справки за отделно училище или за цяла класация
- **Тъмна/светла тема** — следва настройката на устройството, с бутон за смяна
- **Вграждане (embed)** — графиките могат да се вграждат в други сайтове чрез iframe ([документация](https://ivandavidov.github.io/nvo/embed/))
- **Обобщена статистика** — преглед на общите тенденции по класове и години
- **JSON API** — статичен API с данни за училища, градове и класации ([документация](https://ivandavidov.github.io/nvo/api/v1/))
- **Блог** — статии, анализи и ръководства за родители ([блог](https://ivandavidov.github.io/nvo/blog/))
- **Kaggle dataset** — CSV данни и анализ notebook ([Kaggle](https://www.kaggle.com/datasets/johnddavidson/bulgarian-school-exam-results-20182025))

## Технологии

- **Frontend** — статичен HTML + CSS + ES модули (без build стъпка), хостван на GitHub Pages; светла и тъмна тема върху собствена дизайн система (`docs/css/site.css`), шрифт Inter
- **Графики** — [Highcharts](https://www.highcharts.com/) (лицензиран)
- **PDF генериране** — [jsPDF](https://github.com/parallax/jsPDF) + AutoTable
- **Обработка на данни и страници** — Java 21 инструмент (Maven), който нормализира CSV/XLSX файловете и генерира JSON данните, API-то и HTML страниците от Mustache шаблони
- **XLSX обработка** — Apache POI

## Локално стартиране

### Само преглед на сайта

```bash
python3 -m http.server 8090 -d docs
```

Отворете `http://localhost:8090/` в браузъра.

### Пълно регенериране на данните

Изисква Java 21+.

```bash
./all.sh
```

Това компилира Java инструмента, нормализира CSV/XLSX файловете и регенерира данните, API-то и всички генерирани страници (класове, училища, градове и години, балове, начална страница, блог), както и `sitemap.xml`.

## Структура на проекта

```
docs/                  GitHub Pages root (статичният сайт)
  index.html           начална страница
  4/, 7/, 10/, 12/     страници по класове (+ embed.html, класации по градове и години)
  school/              генерирани профилни страници за всяко училище (по код)
  7/balove/            страници за минимални и максимални балове по паралелки след 7 клас
  stats/               обобщена статистика
  blog/                статичен блог със статии и анализи (списъкът е в posts.json)
  za-proekta/          методология, източници, контакти и подкрепа
  api/v1/              статичен JSON API
  embed/               документация и генератор за вграждане
  data/                JSON данните за фронтенда (генерирани)
  js/                  ES модули (core/, ui/, pages/) и данните за баловете
  css/                 дизайн система (site.css) и стилове на блога
data/
  mon/                 сурови CSV файлове от data.egov.bg
  ruo-{регион}/        файловете на РУО за баловете след 7 клас
  normalized/          нормализирани CSV файлове (генерирани)
java/                  Maven проект: обработка на данните, API и генериране на страниците (шаблони в src/main/resources/templates/)
kaggle/                Kaggle dataset (CSV експорт, notebook, cover image)
```

За пълна техническа документация виж [AGENTS.md](./AGENTS.md).
